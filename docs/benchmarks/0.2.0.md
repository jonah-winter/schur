Schur-lib - Version 0.2.0

# Currently implemented:
## Storage:
All purpose storage structure with basic functions.
## Dimensions:
Matrix dimensions structure with generic validation functions and more specific dynamic implementations.
## Matrix Class:
Matrix class with basic operations.

# Currently working on:
## Lazy Evaluation:
Wrappers for matrix to chain operations and save memory. Also saves time in specific scenarios.

# Planned - Near Future:
## Matrix Multiplication:
Matrix multiplication using SIMD.

# Planned - Far Future:
## GPU Operations:
Vulkan Compute Shader, CUDA, and Metal are planned for use with matrix operations.
## Graphics Integration:
Specialization for common matrix sizes (2x2, 3x3, 4x4) and specific operations for these types.
Vulkan- and possibly OpenGL-specific operations to make graphics math easier.
