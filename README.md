# Schur
A matrix arithmetic library with a small quaternion implementation. All header files. It's in version 1.0 and I think it will stay that way. There's nothing like decomposition or inverse in this, just basics like transpose, add, subtract, multiply.

# basic use
There are some test files in the tests/ directory.

# install
```bash
git clone https://github.com/jonah-winter/schur
cd schur
```
